折痕垂直平分对应点的连线。

「翻折前后图形成轴对称：对应角相等、对应边相等、对称点连线被对称轴垂直平分」

先判题目目标——求角度用对应角，求线段长用对应边，由垂直构造直角三角形用第三条性质。

← 上一节 · 瓜豆原理问题下一节 · 矩形的折叠 →

核心思想：三条性质对三类问题

① 对应角相等

用于求角度；特殊对称出现 30°/45°/60° 特殊角，进而得到特殊图形。

② 对应边相等

用于求线段长，配合勾股定理、中位线、相似三角形。

③ 垂直平分

连对称点得垂直 → 直角三角形 / 三垂直全等相似 / 三角函数。

引例1 · 对应角相等（翻折求角）翻折动画
2019·江西：∠CDE = 20°
∠ADB=100°、∠ADC=80°，翻折 ∠ADE=100°，∠CDE=100°−80°=20°。拖滑块看 △ABD 沿 AD 翻折。
引例2 · 特殊对称出现 30°
2018·毕节：AM = 2√3（选B）
翻折 + 角平分线 → ∠DAM=∠MAN=∠NAB=30°；Rt△ADM 中 AM=AD/cos30°=2√3。
引例3 · 两次翻折出现 60°
AB = √3
两次翻折 → ∠AED=∠DEA′=∠A′EB=60°；A′C=A′B′=1，AB=DC=√3。
引例4 · 对应边相等（中位线）
2019·朝阳：FG = √3+3
折叠使 A、C 都与 B 重合 → AE=BE=2√3、CD=BD=4；FG 是 AC 中位线 = ½AC。
引例5 · 两次折叠（相似求面积）
2019·杭州：S = 10+6√5
∠FPG=90° → △A′EP∽△D′PH，面积比 4:1 → 相似比 2:1，解得 a=2，AD=5+3√5。
引例6 · 对称点连线垂直（相似）
2018·襄阳：AP = 16√2/3
沿 BD 折叠 A→P，AP⊥BD，△ABE∽△DAB；AB=4、AD=8√2、BD=12，AH=8√2/3，AP=2AH。
引例7 · 等积法求点到直线距离翻折动画
2019·重庆：D 到 BC′ 距离 = 3√21/7（选B）
△BDC 沿 BD 翻折，CC′⊥BD；C′F=√3、BC′=√7，等积法 DH=2S/BC′=3√21/7。拖滑块看翻折。
模型总结 · 三性质的选用
求角 / 求边 / 由垂直构造
归纳三条性质分别对应哪类问题，串联引例1–7 的选用思路。

课堂使用建议

  • 先判目标再选性质：求角度优先找对应角相等，求线段长优先找对应边相等，见到翻折后的垂直连线想第三条性质。
  • 标「翻折动画」的引例1、引例7 可先拖滑块观察图形从原位翻折到对称位，再展开分步解析。
  • 特殊角是本讲线索：引例2 的 30°、引例3 的 60° 都由翻折 + 角平分线/两次翻折得到，讲清“对称如何产生特殊角”。
  • 引例4 强调对应边相等后接中位线；引例5 强调面积比转相似比；引例6、7 强调由垂直转相似/等积法。
