阿氏圆问题 · 互动课件

「阿氏」取自古希腊几何学家阿波罗尼奥斯的名字。

动点 P 在圆上运动，求 PA + k·PB（0<k<1）型加权最值：逆用阿氏圆构造定点，把带系数的线段换成普通线段，化加权为最短路径。

核心思想：逆用阿氏圆，化加权为普通线段

① 阿氏圆的定义

PA:PB = k（k≠1）的点集是圆，即 PA = k·PB。带系数的 k·PB 可转化为普通线段 PA——问题化为 PA₁+PA₂ 型。

② 逆用：由圆定出另一个定点

给圆、给一个定点 A 与系数 k，用「特殊位置 M、N」或「母子相似 OP²=OA·OB」确定 B，使 PB = k·PA 恒成立。

③ 化折为直

PA + k·PB = PA + PC ≥ AC，取等时 P 在 AC 与圆的交点处。系数 = 圆半径 ÷ 圆心到定点距离。

模型认识 · 定义与证明

阿氏圆：比例 → 圆（k = 2）

内/外角平分线定理 + 定边对直角，证明轨迹是圆。拖动 P 验证 PA:PB 恒为定比。

性质与应用

五点共线 · 定比相同 · OP² = OA·OB

三条性质的交互验证：拖动 P，观察 OP² 恒等于 OA·OB，母子相似三角形实时重画。

引例 1 · 已知 A、B 求圆轨迹

A(−1,0)、B(3,0)、PA:PB=3:1 → 圆心 (7/2,0)

由定比分别找内分点 M、外分点 N，轨迹圆圆心即 MN 中点——给 A、B 求圆。

引例 2 · 已知圆求点 B

两种思路定 B：特殊位置 / 母子相似

给圆、A、k 反求定点 B：思路 1 用 M 处 MA:MB=3:1；思路 2 用 OP²=OA·OB，都得 B(3,0)。

引例 3 · 最值设计

PQ + ⅓PA 的最小值 = √5

逆用阿氏圆构造 B 使 PB=⅓PA，化 PQ+⅓PA 为 PQ+PB≥BQ。拖动滑块看取等时刻。

引例 4 · 比例系数的分析

½PA + PB 的最小值 = √10

Rt△ 中由 CP²=CM·CA 定出 M(CM=1)，PM=½PA。思考：为什么是 ½？若求 PA+k·PB，k=⅔？

模型总结 · 通法

阿氏圆三步法：识 · 构 · 求

三要素 + 确定构造点的两条思路 + 三步法归纳，与胡不归、将军饮马横向对比。

课堂使用建议

  • 先拖后讲：先让学生拖动 P 点滑块观察「PA:PB 恒为定值」「OP² 恒等于 OA·OB」等定值现象，再勾选"显示辅助线"揭示 M、N 与相似三角形。
  • 引例 3、4 页把滑块默认停在最优位置 P*：打开即可看到取等时刻，再拖离 P* 观察最小值如何被"错过"。
  • 三条性质是钥匙：01 页重点讲清 OP²=OA·OB 母子相似，它是引例 2、4 确定构造点的计算工具。
  • 横向对比讲：动点在直线上 → 胡不归（构造角转化）；动点在圆上 → 阿氏圆（构造点转化）；都归结为"两点之间线段最短 / 化加权为普通最短路径"。
