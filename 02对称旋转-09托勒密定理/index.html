托勒密定理的应用 · 互动课件

圆内接四边形，两组对边乘积之和等于两条对角线的乘积。

「对角线的乘积，等于两组对边乘积之和」——《初中压轴题是怎样练成的》

前面几节的四边形都带着「邻边相等 + 对角互补」，一条边转过去就出全等。 本节把条件削弱到只剩对角互补（四点共圆）：旋转全等没有了，但两条对角线与四条边仍被 AC·BD = AB·CD + AD·BC 钉死。等边、等腰直角、一般三角形三种形态， 加上 2019 威海那道引例，全部是这一条式子的变装。

核心思想：一条式子，三种系数

① 通分 + 截长

对角线 AC 做公共分母，另一条对角线 BD 被截成 BE+DE 两段，分别对应两组对边乘积。

② 系数 = 底边比腰

等边出系数 1（DB=DA+DC），等腰直角出 √2（√2AD=BD+CD），一般三角形出 a:b:c。

③ 不共圆就取不等号

任意凸四边形有 AC·BD ≤ AB·CD+AD·BC，等号当且仅当四点共圆 —— 定理是这个不等式的极值点。

知识导航

模型认识 · 邻边相等退化成四点共圆

拖 D 沿圆滑动：AC·BD 与 AB·CD+AD·BC 永远相等（差值 0.000）。

定理证明

截长 + 两次相似，一行不多

在 BD 上取 E 使 ∠BAE=∠CAD，两个乘积同时成立，拖动 E 看两个偏差一起归零。

推广

托勒密不等式：BE+DE ≥ BD

截长法搬到圆外，三角形两边之和接管证明；D 一离开圆，比值就从 1 掉下去。

应用一

等边三角形：DB = DA + DC

三条边相等，乘积直接降级成和；换个弧，结论换成 DA = DB + DC。

应用二

等腰直角三角形：√2·AD = BD + CD

系数 √2 就是「底边比腰」；D 换到弧 AC 时变成 BD = √2·AD + CD。

应用三 · 模型总结

a·AD = b·BD + c·CD

三条边写成 a:b:c，定理变成通用公式；5-6-7 三角形上拖 D 验证。

引例（1）· 2019 威海

截长法与补短法，两条路证 BD = AD + CD

BD 上截 DM=DA 造等边三角形，再证 △AMB ≌ △ADC；M 点随 D 滑动实时可见。

引例（2）· 类比探究

直径 + 30°，系数换成 2 与 √3

BD = CD + √2·AD、BD = √3·CD + 2AD、b·BD = a·AD + c·CD，三个结论一条思路。
