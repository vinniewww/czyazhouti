胡不归问题 · 互动课件

「胡不归？胡不归？」—— 老人弥留之际的念叨

同样一段路，走在驿道上和砂石地上，耗时不同。

少年在驿道上快、在砂石地上慢，怎样走路才能最早到家？
这是一类 PA+k·PB（0<k<1）型加权最值问题：转化带系数线段，化加权为普通最短路径。

← 上一节 · 将军饮马下一节 · 阿氏圆问题 →

核心思想：转化 k·AC，化加权为直线

① 找方向不变的线段

k·AC 能转化，是因为 AC 方向不变；系数若在方向变化的线段上，此法失效（考虑提系数）。

② 构造角 sinα = k

作 Rt△ 使斜边 1、对边 k，得角 α；沿 α 作射线 AD，则对任意 C 有 CH⊥AD ⇒ CH = k·AC。

③ 垂线段最短

BC + k·AC = BC + CH ≥ B 到射线 AD 的距离，B、C、H 共线时取等。系数 >1 先提出去。

课程路径（5 个互动页面）

模型认识

胡不归模型（k = 1/2）

驿道 + 砂石地行程问题。构造 sin∠DAN = k 的射线，CH = k·AC，最小值 = B 到 AD 的距离 2+5√3/4。

引例 · 现成的角

2019·长沙 · 等腰三角形中的转化

AB=AC=10，tanA=2 ⇒ sin∠ABE=√5/5 现成可用。CD+(√5/5)BD 最小 = 4√5 = BE。

关键一步 · 变式 1

自己动手构造角 α（k 滑块联动）

没有现成角时：作 Rt△ 斜边 1、对边 k。拖 k 滑块，射线、直角三角形、最优位置全部实时重画。

变式 2 · 系数大于 1

√5·CD + BD 的最小值

k>1 无法构造，提出 √5 化为 √5(CD+(√5/5)BD)。最小值 = √5×4√5 = 20。

适用条件 · 边界情形

k 的上限：垂足不能掉队

s = AB·cos(α+β) > 0 才有内部最优；k 越过 cos β ≈ 0.848 时最优退化为 C=A、min = AB。拖 k 滑块亲眼观看退化过程。

课堂使用建议

  • 先拖后讲：先让学生拖滑块观察目标量变化（右侧范围条指针实时移动），再勾选"显示辅助线"揭示作法。
  • 构造夹角页是重点：拖动 k 滑块，射线 AD、Rt△（斜边 1、对边 k）、最优位置 C 联动重画——直观体会"方向不变，方能造角"。
  • 与将军饮马对比讲：将军饮马是"对称转化"，胡不归是"造角转化"，都归结为"两点之间线段最短 / 垂线段最短"。
