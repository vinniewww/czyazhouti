构造辅助圆问题 · 互动课件

到定点的距离固定，动点就走在圆上。

「最值必有动点——分析位置之外，更可追寻轨迹；直线与圆是最常见的轨迹，本讲专攻轨迹为圆的情形」

动点满足「到定点距离=定值」→ 轨迹是圆；动点对定边张定角 → 轨迹是圆弧。定圆之后，用点-圆、线-圆最值一举求最值。

核心思想

① 寻

找轨迹：定长（PF=CF）→ 圆；定角（∠APB=90°/120°）→ 圆弧。

② 定

定圆心半径：定长圆心即定点；定角圆心在定边中垂线（90°取中点，120°作等腰，注意同/异侧）。

③ 求

点-圆最值 PQ=PO±r、线-圆最值 MN=d±r、轨迹弧长=弧所对圆心角对应弧，共线时取最值。

模型认识 · 点-圆与构造辅助圆
圆的定义 / 轨迹即圆
前言 + 圆的定义与构造辅助圆；点-圆：PQ 最大 = PO+r、最小 = PO−r，拖 Q 沿圆验证。
引例1 · 点-圆最值应用
OC=5，r=3：AB 最小 = 4
∠APB=90° 且 OA=OB → OP=AB/2；OP 最小=2 → AB 最小=4。
引例2 · 线-圆最值应用
y=¾x−3：S△PAB 最大 = 21/2
线-圆：点到直线距离最大 = d+r；S=½AB·h，拖 P 验证 10.5。
定边对直角 · 引例4
翻折轨迹圆：PH 最小 = 6/5
圆周角定理推论：直径对直角；翻折 PF=CF=2 → 轨迹圆，PH=16/5−2。
引例5 · 定边对直角应用
正方形 BE=CF：PC 最小 = √5−1
BE=CF → AE⊥BF → ∠APB=90° → P 轨迹以 AB 为直径；PC=OC−1。
定边对定角 · 引例6
CE⊥AD：BE 最小 = √13−2
圆周角定理 + 定角轨迹圆弧；E 轨迹以 AC 为直径，BE=BM−2。
引例7 · 轨迹圆弧最值
等边△ABC：CP 最小 = 2√3/3
BE=CF → ∠APB=120° 对定边 AB → 圆弧轨迹；CP=OC−OP。
引例8 · 定边对直角（AG 最小）
EF 过中心：AG 最小 = √10−√2
2019·苏州园区一模：AE=CF → EF 过中心 O，∠BGO=90° 对定边 BO → G 轨迹圆；AG=AM−r。
引例9 · 定边对定角（轨迹弧长）
∠AFB=120°：F 路径长 = 2√3π/3
2020·大庆：△ABD≌△BCE → ∠AFB=120° 对定边 AB → 圆弧轨迹；弧长=120/360×2π√3。
引例10 · 动静互逆（OC 最大）
固定矩形转坐标系：OC 最大 = 8
2019·益阳改编：A 在 x 轴、D 在 y 轴 → ∠AOD=90° 对定边 AD → O 轨迹圆；OC=OM+MC=3+5。

课堂使用建议

  • 先拖后讲：每页先让学生拖滑块看数值变化（PQ、S、PH、PC、BE、CP、AG、OC），再展开解析步骤。
  • 强调轨迹意识：本讲灵魂是「由定长/定角先判轨迹」，遇到动点先问一句“它的轨迹是什么”。
  • 对比讲解：点-圆与线-圆都是「共线取最值」；定边对直角与定边对定角都是「找圆心半径」；引例8/9/10 分别对应「隐藏定边」「轨迹弧长」「动静互逆」三个进阶视角。
  • 引例9 圆心与动点同侧、引例7 圆心异侧：讲清「定角→圆心侧别」随动点位置变化。
  • 引例10 重点演示动静互逆：固定矩形、旋转坐标系，把「点在轴上滑动」翻译成「定边对直角」。
